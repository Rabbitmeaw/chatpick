拾聊 ChatPick · macOS 使用说明

安装

1. 确认电脑使用 macOS 13 或更新版本，且安装包与电脑芯片匹配。
2. 打开 DMG，把「拾聊 ChatPick」拖到「应用程序」，再从「应用程序」打开。
3. 如果系统因无法验证开发者而拦截，请先尝试打开一次，再到「系统设置 → 隐私与安全性」，在拾聊提示旁点「仍要打开」。

安装包使用临时签名，未做 Apple 公证。如果系统提示应用已损坏，请从项目发布页重新下载；仍有问题请反馈提示原文。
Apple 官方说明：https://support.apple.com/zh-cn/102445

生成第一份报告

在「模型设置」填写服务商提供的 Base URL、Model 和 API Key，再选择聊天来源、频道和日期。
快速上手：https://github.com/Rabbitmeaw/chatpick#生成第一份报告

个人账号读取默认关闭。开启后，拾聊使用你的 Discord 登录 Token 自动读取所选频道的消息。Discord 禁止这种普通账号自动化。即使你只读取自己有权查看的频道，账号也可能被停用。

退出与更新

关闭窗口后，已启用的后台任务仍可运行。点击 Dock 或菜单栏的拾聊图标可以重新打开窗口；选择「退出拾聊」会停止后台服务。
更新时替换「应用程序」里的拾聊即可。配置和历史保存在 ~/Library/Application Support/ChatPick，凭据保存在系统钥匙串。
